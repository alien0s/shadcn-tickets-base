# Ticket System - Monorepo

Sistema de tickets com frontend React e API Fastify.

## Instalação
```bash
npm install -g pnpm
pnpm install
```

## Desenvolvimento
```bash
# Rodar tudo
pnpm dev

# Apenas API
pnpm dev:api

# Apenas frontend
pnpm dev:web
```

## Testar API
http://localhost:3000/api/health
